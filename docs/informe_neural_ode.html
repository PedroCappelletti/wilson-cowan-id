Simulador (Wilson-Cowan) vs Neural ODE aprendido

Comparación de comportamiento en lazo abierto y lazo cerrado · estímulos tipo pulso · ITBA 2026

El simulador es el modelo de Wilson-Cowan verdadero (genera los datos). El Neural ODE es el modelo de estados f(x,P,Q) aprendido de esos datos, entrenado con los estímulos nuevos (tipo pulso). Se mide qué tan parecido se comporta el modelo aprendido al real.

1 · Lazo abierto — respuesta libre al mismo estímulo

Se aplica el mismo estímulo (P, Q) a ambos desde la misma condición inicial y se comparan las trayectorias. Incluye estímulos held-out (que el Neural ODE no vio en entrenamiento).

2 · Lazo cerrado — bajo el controlador IMC

El controlador IMC se diseña con los pesos aprendidos por el Neural ODE (θ̂ = wEE=6.407 · wEI=4.818 · wIE=5.994 · wII=1.205) — no con los verdaderos. Es el caso honesto: el controlador solo conoce lo identificado. El mismo controlador maneja al simulador y al Neural ODE como planta, siguiendo la referencia theta-gamma. El seguimiento es prácticamente idéntico → un controlador diseñado solo con los pesos aprendidos controla el sistema verdadero igual de bien: el error de identificación no degrada el control, y el Neural ODE es una planta controlable válida.
