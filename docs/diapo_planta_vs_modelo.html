La misma ecuación, dos versiones

El simulador usa el Wilson-Cowan completo. El modelo usa una versión simplificada y le suma una red.

Simulador · genera los datos

Wilson-Cowan completo

La ecuación original de 1972.

τ dE/dt = −E + (1 − r·E) · S( w·E − w·I + Pef − θ )

Refractariedad La neurona que acaba de disparar no puede repetir. Frena la respuesta cuanto más activa está.
La luz que llega ≠ la que comandás El canal óptico tarda en abrirse y satura. Entra Pef, nunca P.

Modelo · lo que entrenamos

Wilson-Cowan simplificado + red

Le falta física. La red intenta reponerla.

τ dE/dt = −E + (1 − r·E) S( w·E − w·I + P − θ ) + g(I, E)

El factor no está Ésa es la simplificación: se descarta y la entrada entra sin deformar.
Red neuronal Se suma a la derivada para tapar el hueco. Ve sólo el estado (I, E).

El hueco entre las dos es lo que la red tiene que aprender — y por eso se llama gray-box.
