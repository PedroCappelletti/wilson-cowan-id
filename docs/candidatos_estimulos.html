Candidatos de estímulo para el dataset del Neural ODE

Entradas P, Q para entrenar la planta controlable · proyecto Wilson-Cowan + PINN · ITBA 2026

Para qué se elige. El modelo de estados (Neural ODE) tiene que aprender a responder a estímulos variados para luego responder al controlador. Criterios: (1) excitación persistente para identificar bien un sistema no lineal, (2) relevancia fisiológica / que se use en estimulación neural real, (3) realizable por actuación optogenética (on/off). Decisión tomada: no usar senoidales (seno, multiseno, chirp); priorizar entradas tipo pulso/escalón.
Escalas: muy alta alta media baja  ·  Estado: recomendado candidato descartado / baseline

Mezcla recomendada para el dataset

Cubre los tres frentes con entradas todas tipo pulso/escalón (sin senoides):

  • APRBS ⭐ — el caballo de batalla para identificabilidad no lineal (amplitudes × frecuencias).
  • Theta-gated gamma ⭐ — el régimen fisiológico del propio proyecto (lo que el controlador induce).
  • Onda cuadrada / tren de pulsos — variando frecuencia y duty (DBS / optogenética).
  • PRBS — banda ancha, clásico de identificación.
  • Tren de Poisson — naturalista (estadística de spikes).
  • Escalón (box) — baseline.
Por qué esta mezcla. APRBS + PRBS aportan la excitación persistente que necesita identificar un sistema no lineal. Theta-gated gamma + tren de pulsos + Poisson aportan relevancia fisiológica y se parecen a lo que el controlador comanda (y a la estimulación real: DBS, optogenética). El escalón queda de referencia. Todo es realizable on/off → compatible con actuación optogenética. Se descartan seno/multiseno/chirp por no ser fisiológicos ni on/off.
